# Rocket Fin Optimizer

An interactive Python Streamlit application for designing and analyzing a legal single-stage model rocket using an Estes F15-8 motor.

## Features

- Rocket dimension inputs
- Mss distribution table
- Loaded mass calculation
- Center of gravity calculation
- Center of pressure estimate
- Static margin calculation
- Fin flutter screening
- Fin geometry optimizer
- F15-8 mass warning system
- Rocket and fin visualizations
- CSV and JSON export

## Safety note

This tool is for legal model rocket geometry only. It does not design motors, propellants, explosives or weapons.

Final rocket designs should be validated in OpenRocket or RockSim before building or launching. Always follow local laws, launch site rules and model rocket safety codes.
